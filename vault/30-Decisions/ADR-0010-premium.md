# ADR-0010 Premium, sold once

- **Status:** accepted (2026-09-11)
- **Closes branch:** [[Branch Register]] B14 (monetization). Resolves Q6 in [[Open Questions]].
- **Decision:** The game is a **premium one-time purchase**. No in-app purchases, no ads, no energy. Monetization details (price, platforms, demo) are deferred until the game is built and verified fun.
- **Consequences:** Reinforces [[ADR-0002-roguelike-flavor]]'s guardrail: meta progression widens options and never inflates stats, because there is no commercial pressure to sell power. Web build can be the free demo or the full game; decide later.
- **Rewind:** Free until launch planning.
